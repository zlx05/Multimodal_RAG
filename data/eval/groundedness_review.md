**expected**：`doc_3f570a771fd1`  ·  **retrieval_hit**：OK  ·  **sources**：4 条

> 在含 \(n\) 个元素的顺序表中，若在第 \(i\) 个位置插入新元素，需要将原第 \(i\) 到第 \(n\) 个元素各后移一位，因此需移动 **\(n-i+1\) 个元素**。[1]

```go
type Season int

const (
    Spring Season = iota
    Summer
    Autumn
    Winter
)

func (s Season) String() string {
    switch s {

        return "Spring"
    case Summer:
        return "Summer"
    case Autumn:
        return "Autumn"
    case Winter:
        return "Winter"
    default:
        return "Unknown"
    }
}
```
