# Mintlify Reference Summary

Source: https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/mintlify

This is the local implementation summary of the Mintlify entry from `awesome-design-md`. The upstream file is linked above; the project-specific rules in the root `DESIGN.md` take precedence.

## Key Direction

- Documentation-first layout with a sidebar, readable main content, and a right-side table of contents or context rail.
- Inter-style UI typography with a mono face for code and technical metadata.
- High-contrast text, restrained surfaces, and generous reading rhythm.
- Green accent for selected, successful, or high-confidence states.
- Source navigation and page context remain close to the content being read.

## Useful For Context Lab

- Chat answers with a source/evidence rail.
- Original document preview and chunk inspection.
- Page references, content types, OCR confidence, and metadata.
- Long-form study material and source-grounded explanations.

## Adaptations Required

- Do not copy Mintlify's marketing gradients or pill-heavy CTA treatment.
- Use IBM Blue as the product accent and reserve green for evidence/status.
- Collapse the right rail into a drawer or disclosure panel on smaller screens.
- Keep Agent traces collapsed by default so the answer remains the primary reading surface.
